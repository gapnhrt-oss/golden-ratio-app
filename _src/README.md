# المصدر

- **عدّل هني:** `_src/index.html` (الكود الكامل بالشروحات).
- **بعد أي تعديل:** `node _src/build.mjs` → يطلع `index.html` المضغوط بالجذر (هذا اللي ينخدم بالموقع).
- مجلد `_src` ما ينشر بالموقع (GitHub Pages / Jekyll يتجاهل المجلدات اللي تبدي بـ `_`).
- `sw.js`: الصفحة تفتح من الكاش وتتحدث بالخلفية — غيّر `SHELL_C` لو تبي تجبر الكل ينزل نسخة جديدة.
